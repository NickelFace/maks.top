<div class="rdm-section-label">Ключевые темы экзамена</div>
<div class="tips-grid">
<div class="tips-header"><div>Тема</div><div>Что нужно знать чётко</div></div>
<div class="tip-row"><div class="tip-cell">Subnetting</div><div class="tip-cell">Считать на скорость: сколько хостов, адрес сети, broadcast. VLSM без калькулятора.</div></div>
<div class="tip-row"><div class="tip-cell">STP root bridge</div><div class="tip-cell">Выбирается по наименьшему Bridge ID (priority + MAC). Portfast только на access-портах.</div></div>
<div class="tip-row"><div class="tip-cell">OSPF DR/BDR</div><div class="tip-cell">Выбирается по highest router-id / highest loopback / highest interface IP. Broadcast vs P2P.</div></div>
<div class="tip-row"><div class="tip-cell">ACL порядок правил</div><div class="tip-cell">Первое совпавшее правило применяется. Implicit deny в конце. Стандартный ACL: ближе к dst.</div></div>
<div class="tip-row"><div class="tip-cell">NAT PAT</div><div class="tip-cell">ip nat inside/outside на интерфейсах. overload = PAT. Проверить show ip nat translations.</div></div>
<div class="tip-row"><div class="tip-cell">HSRP vs VRRP</div><div class="tip-cell">HSRP: Cisco proprietary, active/standby. VRRP: open standard, master/backup. GLBP: load balancing.</div></div>
<div class="tip-row"><div class="tip-cell">802.1Q vs ISL</div><div class="tip-cell">802.1Q: стандарт, 4-байт тег, native VLAN не тегируется. ISL: устаревший Cisco, инкапсуляция.</div></div>
<div class="tip-row"><div class="tip-cell">WPA2 vs WPA3</div><div class="tip-cell">WPA3: SAE вместо PSK, обязателен для Wi-Fi 6. WPA2: AES/CCMP. WEP = уязвим, не использовать.</div></div>
</div>
